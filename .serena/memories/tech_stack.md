# Tech stack
- Python ≥3.13 required; CI matrix Linux 3.13–3.14 plus Windows 3.14. Dev machines: Fedora Linux and Windows 11 (with WSL2 Ubuntu, mirrored networking: one CLI test that connects to a closed localhost port hangs there), all Python 3.14. On Windows the POSIX-only tests (quit listener, permission bits) skip and the `windows_only` file-safety tests run; the `msvcrt` Q listener is tested with a fake `msvcrt`.
- Runtime deps (`requirements.txt`, `>=` lower bounds only, never tested as minimums): `ollama`, `openai` (LM Studio OpenAI-compatible API), `pillow`, `pyexiv2` (Exiv2 binding; not thread-safe; can't open non-ASCII paths on Windows, so only fed bytes), `tqdm`.
- Dev deps (`requirements-dev.txt`): pytest, pytest-cov, `ruff==` exact pin (CI reads Ruff version from it). `requirements-dev.lock` = uv-generated hash lock, used only by CI; regen command + gotchas in `AGENTS.md` CI section.
- Not packaged: `pyproject.toml` holds only `[tool.ruff]` (py313, line-length 120, default rules plus `BLE` and `RUF100`) and `[tool.coverage.run]` (incl. `patch = ["subprocess"]`, so CLI subprocess tests count; stray empty `.coverage.*` files from tqdm's `resource_tracker` child are git-ignored). pytest config in `pytest.ini`.
- CI: GitHub Actions `.github/workflows/ci.yml` — Ruff check + format check, pytest+coverage matrix (Linux + one Windows job; both 3.14 jobs upload coverage, artifacts `coverage` and `coverage-windows`, both fed to Sonar), SonarQube Cloud scan (`sonar-project.properties`; `SONAR_TOKEN` as Actions + Dependabot secret; scan step gated on `env.SONAR_TOKEN != ''`, so fork PRs skip with a warning and get no quality-gate status). Jobs have `timeout-minutes`, checkouts `persist-credentials: false`. `.github/workflows/osv-scanner.yml` — `google/osv-scanner-action` reusable workflows (full scan on push/schedule/manual, PR diff scan on PR/merge_group with `upload-sarif` skipped on fork PRs; scans `--lockfile=requirements.txt:requirements-dev.lock --no-resolve -r ./`). `.github/dependabot.yml` (schedule/grouping/cooldown live only there): GitHub Actions; pip entry ignores `*` (also blocks security PRs) because Dependabot can't regenerate the uv lock. Lock bumps are manual: regen command + `--upgrade`/`-P <pkg>` (plain regen keeps existing pins). Dismissed Sonar false positives listed in `AGENTS.md`.
- Backends: Ollama `http://localhost:11434`, LM Studio `http://localhost:1234`; one `--model` default `qwen3-vl:8b` (Ollama naming; LM Studio ids differ, e.g. `qwen/qwen3-vl-8b`, so pass `--model`). LM Studio accepts images only if the GGUF model's vision projector (`mmproj-*.gguf`) is downloaded, else HTTP 400 "does not support image inputs". Both clients get `--timeout` (default 600s) via `_create_client()`; LM Studio client has `max_retries=0`.
- Also installed locally, NOT configured in repo: `basedpyright` (Serena LSP via `project.yml`) and, on Fedora, `black`. Their output reflects user-global defaults; never use black (Ruff format is authoritative).

- Backend image inputs are guarded snapshots: Ollama receives bytes rather than a path; LM Studio encodes bytes. POSIX filesystem protections use dir_fd/O_NOFOLLOW; Windows uses ctypes Win32 handles (pinned folders, DACL-carrying share-0 temporaries, handle rename), verified on NTFS only.
